## 검증 전략과 환각 검증

### 검증 전략 / 검증 결과 
- **검증 방법:** 공식 자료·도움말 확인과 실제 ChatGPT 실행 테스트를 병행한다.
- **불확실한 정보:** 결과물에 '확인 필요'를 표시하고 공식 자료/직접 실행 절차를 제안하도록 한다.
- **우선순위:** 내용의 사실 정확성을 가장 중요하게 평가한다.

| 구분 | 검증 대상 | 확인 방법 | pass/fail |
|---|---|---|---|
| 사실 오류 | ChatGPT 기능의 실제 제공 여부 | 공식 도움말과 사용 화면 확인 | 공식 무료 FAQ·음성 도움말과 실제 무료 계정 화면으로 확인. 무료 계정의 받아쓰기 한도는 공식 문서에 없어 '확인 필요' 유지, 조건부 pass|
| 사실 오류 | 설명된 실습 절차의 실현 가능성 | 실제 기기에서 단계 실행 | 로그인 후 무료 계정 첫 화면입력창 안에 **"Think" 선택**이 있음(공식 FAQ도 무료의 Think 제공을 언급). 현재 자료에는 설명이 없음 , **부분 fail** |
| 지시 준수 | 강의 시간·이론/실습 비율 | 120분 = 36분+84분 계산 | 현재 110분 = 33 + 77(30%/70%), 휴식 10분 별도. 이전 120분 = 36 + 84도 확인, pass |

| 승인 통제 | 강사 승인 단계 준수 | 승인 전 후속 5종 생성 여부 | 커리큘럼 초안 후 '승인' 입력 뒤에 후속 5종 생성, pass |

###  환각 검증 질문 
**Pass 판정:** (A) 정답과 근거를 함께 제시하거나, (B) 모른다고 밝히고 확인 절차를 제안하면 Pass. 두 기준 모두 만족하지 못하면 Fail. 

1. 강의자료에 제시된 ChatGPT 기능은 현재 무료 요금제에서 제공되는가? 근거는 무엇인가?
   **일부**, 텍스트 채팅·무료 한도 설명은 공식 자료 제공하였으나 받아쓰기 한도와 앱 화면은 【확인 필요】, 확인 절차를 제안 함
2. 교육생이 안내된 기기에서 제시된 실습 메뉴와 조작 순서를 실제로 재현할 수 있는가? 재현하지 못했다면 무엇이 달랐는가?
   **일부** | PC 로그인 구간만 재현. 가입·앱·음성은 재현하지 못했으나 이부분을 명시하고 확인 절차를 제안 함.
   **다른 점 2건을 발견**
   - 입력창에 **Think 선택**이 있음(자료에 없음). 무료 화면에는 상단 Chat/Work 탭이 보이지 않았고 본계정(유료) 화면에는 보였음 → 슬라이드 15쪽 PC 캡처(무료 화면)와는 일치
   - **자료의 "새 대화"는 실제 화면의 "새 채팅"과 다름** (강의안 0장 9번·3차시, 스크립트, 슬라이드 15쪽 안내 칩, 구성안). 수정 필요
   - 
3. 강의자료에서 확인할 수 없는 ChatGPT 기능을 사실로 단정했는가, 아니면 '확인 필요'와 확인 절차를 제시했는가?
   **대부분 단정 안했으나 아래 **단정에 가까운 표현**은 보완 필요. '확인 필요'와 절차를 제시 함.
   - "새 대화"(실제는 "새 채팅")는 실제 화면에서 확인한 이름과 다름. "새 채팅"으로 수정
   - 슬라이드 20쪽 음성 입력 순서(마이크 허용 → 말하기 → 글자 확인) 미실행이나 순서를 확정적으로 안내함 
5. ChatGPT 기능의 제공 범위를 설명할 때 공식 자료 또는 직접 확인 가능한 절차를 제시했는가?
   **예(보완 필요)**, 공식 FAQ 근거와 사전 점검표가 있으나 슬라이드에는 출처 표기가 없음 
6. 강의자료에 실제로 존재하지 않거나 확인할 수 없는 메뉴·기능을 만들어 적었는가? 확인 가능한 근거를 제시했는가?
  **일부 있음**, Claude가 그린 예시 그림 3장에 실제와 다를 수 있는 화면 요소가 있음, 대안으로 **예시 표시와 확인 필요** 버튼 추가 함
