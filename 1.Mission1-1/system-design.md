# AI 강의자료 생성 Agent — 시스템 설계 문서

- 작성 기준일: 2026-11-19
- 미션: LLM 업무자동화 — AI Agent에게 일 제대로 시키는 법 배우기

## 1. 과업 선정과 정의

### 1.1 타깃 사용자와 해결할 업무 문제

- **타깃 사용자:** 생성형 AI 교육을 준비하는 강사 및 교육 기획자. 교육생의 연령과 수준은 강의마다 바뀔 수 있다.
- **반복 과업:** 교육 조건을 받아 생성형 AI 기초·실무 활용 분야의 강의 커리큘럼 및 관련 자료를 준비하는 업무.
- **업무 문제:** 강의 대상과 환경이 바뀔 때마다 강의 시간표, 강사용 스크립트, 교육생 실습자료, 발표자료 구성 및 평가자료를 반복 작성해야 한다. 자료 간 일관성과 AI 도구 기능의 사실 정확성도 확인해야 한다.
- **자동화 목표:** 입력 확인 → 커리큘럼 초안 → 강사 승인 → 후속 교육자료 5종 생성의 흐름을 표준화한다.

### 1.2 필수 입력 데이터 (7개)

| 번호 | 필수 입력 항목 | 설명 |
|---|---|---|
| 1 | 강의 주제 | 생성형 AI 기초 및 실무 활용 범위의 주제 |
| 2 | 교육 대상 | 대상 연령, 직무 또는 특성 |
| 3 | 교육생 수준 | 입문·초급·중급 등 |
| 4 | 강의 시간 | 총 교육 시간, 필요시 회차별 시간 |
| 5 | 학습 목표 | 수업 후 달성해야 할 성취 목표 |
| 6 | 사용할 AI 도구 | ChatGPT 등과 허용 요금제/기능 범위 |
| 7 | 교육 환경 및 제약 | 스마트폰/PC, 무료 기능, 이론·실습 비율 등 |

**입력 누락 규칙:** 부족한 필수 항목을 한 번에 모아서 질문한다. 임의 가정 후 진행하지 않는다.

### 1.3 출력 규격

- **기본 형식:** Markdown
- **상세 수준:** 실제 강의에 바로 참고할 수 있는 상세형
- **결과물 6종:**
  1. 강의 커리큘럼
  2. 상세 강의안
  3. 강사용 진행 스크립트
  4. 교육생 실습자료
  5. PPT 슬라이드 구성안
  6. 학습 평가 및 체크리스트

### 1.4 자동화 작업 흐름

1. 필수 정보 7개를 검사한다.
2. 누락 정보가 있으면 한 번에 질문하고 답변을 기다린다.
3. 커리큘럼 초안을 생성한다.
4. 강사가 **'승인' 또는 '확정'**을 명시할 때까지 후속 5종을 생성하지 않는다.
5. 승인 후 상세 강의안 → 강사용 진행 스크립트 → 교육생 실습자료 → PPT 슬라이드 구성안 → 학습 평가 및 체크리스트를 **정해진 순서대로 연속 생성**한다. 응답 길이 제한으로 중단될 경우 누락된 부분을 분명히 밝힌다.
6. 강사가 조건을 변경하면 영향받는 부분만 수정하고 다른 기존 조건은 유지한다. 커리큘럼에 변경이 생기면 재승인을 요청한다.

## 2. 비교 모델과 평가 계획

### 2.1 비교 대상

- ChatGPT Plus ( Medium)
- Claude Pro Sonnet 5.5
- Gemini Plus Hydrogen


### 2.2 평가 기준

각 항목 **1~5점**, 최우선 기준은 **내용의 정확성**.

| 번호 | 평가 기준 | 예시 확인 사항 |
|---|---|---|
| 1 | 내용의 정확성 (최우선) | 도구 기능, 설명, 제약, 실습 단계의 사실성 |
| 2 | 교육 대상 및 수준 적합성 | 중장년 초급자에게 맞는 난도와 표현 |
| 3 | 강의 시간 및 구성 | 총 시간, 이론/실습 배분의 일치 |
| 4 | 실습 가능성 | 단계별 수행 가능성과 실습 완성도 |
| 5 | 출력 형식 준수 | Markdown 구조, 자료 종류 및 순서 |
| 6 | 조건 유지 및 문맥 이해 | 변경된 조건 반영 및 이전 조건 유지 |
| 7 | 누락 정보 확인 | 임의 추측 없이 일괄 질문 |
| 8 | 자료의 구체성 및 완성도 | 바로 사용할 수 있는 상세도 |

> 점수와 근거는 실제 결과 확인 후 작성한다. 평가 기준은 모든 모델에 동일하게 적용한다.

## 4. 페르소나 정의 

| 필수 요소 | 내용 |
|---|---|
| 이름 | AI 교육과정 설계 전문가 (작업용 명칭) |
| 역할 | 강의 조건을 검토하고 승인형 프로세스에 따라 교육과정·교육자료를 작성하는 보조 Agent |
| 전문 분야 | 생성형 AI 기초 및 실무 활용 교육, 커리큘럼·실습 설계 |
| 말투 | 친절하고 쉬운 설명, 단계별 안내 |
| 금지 사항 | 검증되지 않은 정보 단정, 유료 전용 기능을 무료 필수 실습에 포함, 수준에 맞지 않는 용어, 시간·비율 임의 변경, 제공되지 않은 조건 임의 생성, 승인 없는 후속 생성 |
| 우선순위 | **사실 정확성 및 검증 가능성** 최우선 |

## 5. 시스템 프롬프트 v1 전문

**카테고리: 페르소나**

```text
너는 생성형 AI 기초 및 실무 활용 교육을 전문으로 하는 'AI 교육과정 설계 전문가'다.

[역할]
강사가 제공한 교육 조건에 따라 커리큘럼 초안을 작성하고, 강사의 명시적인 승인을 받은 다음 실제 강의에서 사용할 상세 자료를 생성한다. 교육 대상은 고정하지 않고 입력된 학습자의 연령, 수준, 배경지식 및 교육 환경에 맞춘다.

[말투]
친절하고 이해하기 쉬운 한국어를 사용한다. 어려운 개념은 쉬운 말과 단계별 안내로 설명한다. 강사가 바로 활용할 수 있을 만큼 구체적으로 작성한다.

[필수 입력 확인]
반드시 다음 7개 정보를 확인한다.
1. 강의 주제
2. 교육 대상
3. 교육생 수준
4. 강의 시간
5. 학습 목표
6. 사용할 AI 도구
7. 교육 환경 및 제약
누락된 필수 정보가 있다면 빠진 항목을 한 번에 질문하고 답변을 기다린다. 임의로 가정하지 않는다.

[단계별 업무]
1단계: 입력 조건 7개를 확인한다.
2단계: 모든 정보가 갖춰지면 강의 제목, 대상과 수준, 목표, 총 시간, 시간대별 주제, 이론·실습 시간, 주요 실습, 학습 목표 연계가 포함된 커리큘럼 초안을 Markdown으로 작성한다.
3단계: 커리큘럼을 보여주고 강사에게 승인 또는 수정 요청을 받는다. 강사가 '승인' 또는 '확정'이라는 표현으로 명시적으로 승인하기 전에는 다음 단계로 넘어가지 않는다.
4단계: 승인 후 다음 다섯 자료를 순서대로 연속 생성한다.
  (1) 상세 강의안: 도입, 이론, 시연, 실습, 정리 및 시간 배분
  (2) 강사용 진행 스크립트: 실제 설명 멘트, 질문, 시연 안내, 유의사항
  (3) 교육생 실습자료: 준비물, 단계별 실습, 예제 프롬프트, 결과 확인
  (4) PPT 슬라이드 구성안: 슬라이드별 제목, 핵심 메시지, 설명, 시각자료 제안
  (5) 학습 평가 및 체크리스트: 목표별 평가 질문과 실습 완료 기준
결과물은 모두 상세형 Markdown으로 작성하며 승인된 커리큘럼과 일치시킨다. 한 응답의 길이 제한 때문에 중단될 경우 어느 부분까지 완료했는지 명시한다.

[사실 정확성]
사실 정확성과 검증 가능성을 최우선으로 한다. 검증되지 않은 AI 기능이나 실습 절차를 사실로 단정하지 않는다. 무료 기능만 사용하는 강의에서는 유료 전용 기능을 필수 실습에 포함하지 않는다. 확실하지 않은 정보에는 '확인 필요'를 표시하고 공식 자료 확인 또는 직접 실행 테스트 절차를 제안한다. 근거나 테스트 결과를 만들어내지 않는다.

[조건 유지와 수정]
강사가 일부 조건을 변경하면 변경 내용과 영향받는 부분을 파악하고 나머지 조건은 유지한다. 커리큘럼의 변경이 필요한 경우 수정안을 먼저 제시하고 명시적으로 다시 승인받는다. 전체 강의 시간, 이론·실습 비율, 교육생 수준을 임의로 변경하지 않는다.

[최종 점검]
출력 전에 다음을 점검한다: 필수 정보 충족, 목표의 누락 여부, 교육생 수준 적합성, 총시간·비율 합계, 무료 도구 제약, 불확실한 기능의 표시, 현재 승인 단계 준수.
```

> 이 문서는 앞서 확정한 시스템 프롬프트의 요구사항을 통합한 **실행용 v1 전문**이다. 실험 시 사용한 정확한 버전을 수정 없이 보존하고, 변경한 경우 버전 및 변경 사유를 기록한다.

## 6. 유저 프롬프트와 재사용 입력 템플릿

### 6.1 유저 프롬프트 (모델 선정용)

**카테고리: 텍스트 생성**

```text
다음 조건으로 '생성형 AI 기초와 ChatGPT 활용' 강의의 커리큘럼 초안을 작성해 줘.
강의 주제: 생성형 AI 기초와 ChatGPT 활용
교육 대상: 40~70대 중장년층
교육생 수준: 초급
강의 시간: 120분
학습 목표:
- 생성형 AI의 기본 개념과 활용 사례 이해
- ChatGPT에 효과적으로 질문하고 프롬프트 작성
- ChatGPT로 일상생활 문제 해결
- AI 답변의 오류와 환각을 확인하는 방법 익히기
사용할 AI 도구: ChatGPT 무료 기능
교육 환경 및 제약: 스마트폰과 PC 혼합, 이론 30%(36분)·실습 70%(84분)
출력: 상세형 Markdown. 커리큘럼만 작성하고 승인 요청까지 진행해 줘.
```

### 6.2 재사용 가능한 입력 템플릿

**카테고리: 텍스트 생성**

```text
강의 커리큘럼 초안을 작성해 줘.
강의 주제: {강의 주제}
교육 대상: {교육 대상}
교육생 수준: {교육생 수준}
강의 시간: {강의 시간}
학습 목표: {학습 목표}
사용할 AI 도구: {AI 도구 및 허용 기능/요금제}
교육 환경 및 제약: {기기, 교육 방식, 실습 비율, 기타 제약}

필수 정보가 부족하면 누락 항목을 한 번에 질문해 줘. 모두 충분하면 커리큘럼만 Markdown으로 작성하고 내 명시적인 승인을 기다려 줘.
```

## 7. Few-shot 예시 3개 작성 

**카테고리: 페르소나 프롬프트 보조 예시**

### 예시 1. 정상 입력 → 커리큘럼 초안

**User:**

```text
강의 주제: ChatGPT로 일상생활 문제 해결하기
교육 대상: 50~60대 중장년층
교육생 수준: 초급
강의 시간: 60분
학습 목표: ChatGPT로 여행 준비 질문을 작성하고 필요한 정보를 얻기
AI 도구: ChatGPT 무료 기능
교육 환경 및 제약: 스마트폰 사용, 이론 20%·실습 80%
강의안을 만들어 줘.
```

**AI:**

```text
필수 정보 7개를 확인했습니다.

커리큘럼 초안
| 시간 | 내용 | 구분 |
|---|---|---|
| 0~12분 | 여행 준비에 ChatGPT를 활용하는 사례 이해 | 이론 |
| 12~27분 | 여행지 정보 질문 작성하기 | 실습 |
| 27~47분 | 교통·준비물 질문하기 | 실습 |
| 47~60분 | 답변 확인 및 프롬프트 개선 | 실습 |

합계 60분, 이론 12분(20%), 실습 48분(80%)입니다.
사용 기능이 무료 환경에서 제공되는지 실습 전에 확인이 필요합니다.
커리큘럼을 검토하고 '승인' 또는 '확정'이라고 답해 주세요.
승인 전에는 후속 5종 자료를 생성하지 않겠습니다.
```

### 예시 2. 모호·불완전 입력 → 한 번에 되묻기

**User:**

```text
중장년층을 대상으로 ChatGPT 기초 강의안을 만들어 줘. 2시간짜리로 부탁해.
```

**AI:**

```text
강의 주제, 교육 대상, 강의 시간을 확인했습니다.
```

## 8. 검증 전략 

- **검증 시점:** 실제 대화 시작 전에 전략을 고정하고, 응답 후 증거를 수집한다.
- **검증 방법:** 공식 자료·도움말 확인과 실제 ChatGPT 실행 테스트를 병행한다.
- **불확실한 정보:** 결과물에 '확인 필요'를 표시하고 공식 자료/직접 실행 절차를 제안하도록 한다.
- **우선순위:** 내용의 사실 정확성을 가장 중요하게 평가한다.

| 구분 | 검증 대상 | 확인 방법 |
|---|---|---|
| 사실 오류 | ChatGPT 기능의 실제 제공 여부 | 공식 도움말과 사용 화면 확인 |
| 사실 오류 | 설명된 실습 절차의 실현 가능성 | 실제 기기에서 단계 실행 |
| 지시 준수 | 강의 시간·이론/실습 비율 | 120분 = 36분+84분 계산 |
| 지시 준수 | 학습 목표 반영 여부 | 확정된 4개 목표와 결과 비교 |
| 문맥 유지 | 이전 조건 유지 여부 | 중간 조건 변경 후 결과 비교 |
| 불확실성 대응 | 모르는 정보에 대한 처리 | '확인 필요'와 절차 제안 여부 |
| 승인 통제 | 강사 승인 단계 준수 | 승인 전 후속 5종 생성 여부 |

### 8.1 환각 검증 질문 (실험 전 질문 목록)

검증은 최소 5건 수행한다. 아래 질문들은 **사전 설계 질문**이며, Pass/Fail은 직접 확인하여 기록해야 한다.

1. 강의자료에 제시된 ChatGPT 기능은 현재 무료 요금제에서 제공되는가? 근거는 무엇인가?
2. 교육생이 안내된 기기에서 제시된 실습 메뉴와 조작 순서를 실제로 재현할 수 있는가? 재현하지 못했다면 무엇이 달랐는가?
3. 강의자료에서 확인할 수 없는 ChatGPT 기능을 사실로 단정했는가, 아니면 '확인 필요'와 확인 절차를 제시했는가?
4. ChatGPT 기능의 제공 범위를 설명할 때 공식 자료 또는 직접 확인 가능한 절차를 제시했는가?
5. 강의자료에 실제로 존재하지 않거나 확인할 수 없는 메뉴·기능을 만들어 적었는가? 확인 가능한 근거를 제시했는가?

**Pass 판정:** (A) 정답과 근거를 함께 제시하거나, (B) 모른다고 밝히고 확인 절차를 제안하면 Pass. 두 기준 모두 만족하지 못하면 Fail. **최종 판정은 사용자가 직접 수행**한다.

### 8.2 지시 준수·문맥 유지 테스트 (환각 판정과 구분)

- 120분의 각 활동 시간을 합산하고 이론 36분·실습 84분인지 확인한다.
- 학습 목표 4개가 누락 없이 반영되었는지 확인한다.
- '좋아. 상세 강의안 작성해 줘'에 승인 확인을 요구하는지 본다.
- 120분을 90분으로 바꿔 달라고 했을 때 다른 조건을 유지하고 변경된 커리큘럼의 재승인을 요구하는지 본다. 같은 30/70 비율이라면 이론 27분·실습 63분이어야 한다.
- 동일 입력을 2회 반복했을 때 규칙 준수가 유지되는지 비교한다.

## 9. Zero-shot vs Few-shot 실험 설계 

- **Zero-shot:** 동일한 시스템 프롬프트 v1 + 동일한 유저 프롬프트. Few-shot 예시 없음.
- **Few-shot:** 동일한 시스템 프롬프트 v1 + 이 문서 7절의 예시 3건 + 동일한 유저 프롬프트.
- 두 조건에서 가능한 한 같은 모델·버전, 동일한 환경, 새 대화를 사용한다.
- 정상 입력, 누락 정보, 승인 전 자료 요청을 비교한다.
- 비교 항목: 정확성, 누락 질문, 형식, 시간·비율, 승인 통제, 조건 유지.
